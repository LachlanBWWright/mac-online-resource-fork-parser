# Pangea sample resource forks

These samples are copied from the public source repositories for Iliyas Jorio's
modern Pangea Software ports:

- [Nanosaur](https://github.com/jorio/Nanosaur)
- [Bugdom](https://github.com/jorio/Bugdom)
- [Nanosaur2](https://github.com/jorio/Nanosaur2)
- [BillyFrontier](https://github.com/jorio/BillyFrontier)
- [Bugdom2](https://github.com/jorio/Bugdom2)
- [CroMagRally](https://github.com/jorio/CroMagRally)

The terrain resources are one representative level from each game where the
repository includes a `.ter.rsrc` file. Nanosaur's Level 1 terrain is stored as
a flat `.ter` file in the port, so its `Deinon.skeleton.rsrc` is included as a
representative resource fork instead.

The source repositories identify these releases as CC BY-NC-SA 4.0. These files
are included as parser fixtures and remain subject to their upstream terms.
